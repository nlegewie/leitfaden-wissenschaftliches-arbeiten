# 3 Arbeitstypen

Was eine gute Analyse ausmacht, hängt vom Typ deiner Arbeit ab. Bevor du anfängst, solltest du wissen, welche Art von Arbeit du schreibst — und das in der Arbeit auch ausweisen (siehe [Anspruch und Vorgehen](../01-anforderungen/05-analyse-und-evidenz.md#anspruch-und-vorgehen-müssen-zusammenpassen)).

| | Seite | Worum es geht |
|---|---|---|
| 3.1 | [Theoretische Arbeiten](01-theoretische-arbeiten.md) | Theorien vergleichen, anwenden, kritisieren — ohne nur zusammenzufassen |
| 3.2 | [Empirische Arbeiten](02-empirische-arbeiten.md) | Aufbau, Fallauswahl, Datenkritik |
| 3.3 | [Forschungsethik und Datenschutz](03-forschungsethik-und-datenschutz.md) | Einwilligung, Pseudonymisierung, sichere Speicherung |
| 3.4 | [Quantitative Arbeiten](04-quantitative-arbeiten.md) | Zielgröße, Dokumentation, Methodenpassung, Datenquellen |
| 3.5 | [Qualitative Arbeiten](05-qualitative-arbeiten.md) | Anhang, Systematisierung, fünf Kennzeichen guter Arbeit |
